# v0.6.3 — Rawlsian sensitivity analysis

## What this tests

v0.6.3 checks whether **trained Rawlsian DQN** outcomes on `merge-v0` change when we perturb one design parameter at a time, while keeping the rest at the current project defaults (`ego_neighbourhood` scope, safety-mobility experience, default DQN budget).

This is **not** a search for optimal hyperparameters. It answers: *Are the fairness/safety trends from v0.5/v0.6.1 stable under reasonable alternative settings?*

## Parameters selected

| Parameter | Values | Role |
|-----------|--------|------|
| **xi** | 0.05, 0.10, 0.20 | Strength of Rawlsian shaping (+/−xi when scoped min experience improves/worsens) |
| **ego_neighbourhood_radius** | 30, 50, 70 m | Which vehicles enter the maximin set around ego |
| **W_RISK** | 0.0, 0.5, 1.0 | Weight of proximity risk in the experience function (and thus min experience) |

Defaults (used for non-varied factors): `xi=0.2`, `radius=50`, `W_RISK=0.5`, `RAWLSIAN_SCOPE=ego_neighbourhood`.

## Design: one-factor-at-a-time (OAT)

We run **nine** conditions (3×3 sweeps), not a 3³ factorial grid. Each condition trains a **fresh** Rawlsian DQN per seed; results do not overwrite v0.6.1 multi-seed outputs.

## Scripts and outputs

- `run_sensitivity.py` — train + evaluate per variant × seed
- `summarize_sensitivity.py` — aggregate CSVs and plots

| File | Content |
|------|---------|
| `results/v0.6.3_sensitivity/sensitivity_raw_results.csv` | One row per variant × seed |
| `results/v0.6.3_sensitivity/sensitivity_summary.csv` | Mean ± std across seeds per variant |
| `results/v0.6.3_sensitivity/sensitivity_vs_default.csv` | Per-factor comparison to default value within each sweep |
| `results/v0.6.3_sensitivity/plots/` | Bar charts per metric × factor |

Models: `models/sensitivity/{variant_id}/seed_{seed}/rawlsian_dqn.zip`

## Quick vs full run

```bash
python run_sensitivity.py --seeds 0 --quick
python summarize_sensitivity.py

python run_sensitivity.py --seeds 0 1 2 3 4
python summarize_sensitivity.py
```

`--quick` uses fewer timesteps and eval episodes (debug only). Use full settings for thesis-ready numbers.
